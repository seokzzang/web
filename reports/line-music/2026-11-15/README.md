## 파일 구성

- `LINE-MUSIC-상세-분석.html`: 생성 스크립트를 실행하면 만들어지는 이미지 내장 휴대용 문서. 저장소에는 중복 용량을 줄이기 위해 포함하지 않습니다.
- `index.html`: `assets/`의 원본 이미지를 사용하는 가벼운 문서. 폴더째 보관해야 합니다.
- `assets/`: iPhone 미러링 창의 실제 PNG 캡처 49장.
- `evidence/manifest.json`: 촬영 시각, 파일별 SHA-256 및 공식 출처.
- `evidence/screens.jsonl`: 촬영 당시 기록한 화면 설명.
- `evidence/features.json`: 검색 가능한 기능 목록의 원본 데이터.
- `evidence/validation.json`: 문서 구조 및 PNG 검증 결과.
- `content.py`, `build_report.py`: 문서 내용과 생성 스크립트.

## 조사 기준

한국어 기본 UI와 일본어 콘텐츠·AI PlayList 화면이 함께 보였습니다.
동작 확인, 화면 확인, 진입점 확인, 공식 문서 보완을 구분했습니다.

음악 재생과 검색 때문에 감상·검색 이력은 갱신될 수 있습니다.
